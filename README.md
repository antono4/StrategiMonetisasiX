# Toolkit X/Twitter — OCR

Kumpulan materi dan alat bantu untuk strategi monetisasi X/Twitter dengan fokus audiens Tier 1.

## Isi

| File | Isi |
|---|---|
| [`docs/artikel-x-ocr.md`](docs/artikel-x-ocr.md) | Artikel/thread siap posting — versi rapi dari catatan pengalaman |
| [`docs/playbook-x-ocr.md`](docs/playbook-x-ocr.md) | Playbook praktis: peta jalan akun, checklist OCR, formula konten, metrik |
| [`docs/catatan-kritis.md`](docs/catatan-kritis.md) | Yang perlu diwaspadai: asumsi angka, risiko DMCA, platform risk |
| [`tools/tier-desk.html`](tools/tier-desk.html) | Web tool: estimator earning, checklist OCR, caption builder |

## Cara Pakai Web Tool

Buka `tools/tier-desk.html` langsung di browser — tidak butuh server, build step, atau koneksi internet (kecuali font). Semua data disimpan lokal di browser, tidak dikirim ke mana pun.

Tiga bagian:

1. **Estimator** — masukkan total impresi dan komposisi tier, dapat estimasi earning bulanan plus selisihnya dibanding kalau semua trafik dari Tier 3. Angka rasio dan RPM bisa diubah sesuai data akun sendiri.
2. **Checklist OCR** — 10 item kesiapan sebelum gabung program, dengan progres tersimpan otomatis.
3. **Caption Builder** — rakit tiga draft caption English dari topik dan angle, lengkap dengan hitungan karakter dan tombol copy.

## Catatan

- Estimasi earning bersifat indikatif. Rasio 35x itu asumsi kasar dari materi, bukan angka tetap — selalu ganti dengan RPM akun sendiri begitu ada data.
- Syarat program OCR bisa berubah. Selalu cek dashboard resmi.
